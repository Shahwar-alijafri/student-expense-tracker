# 📊 Student Pocket-Money & Expense Tracker

A clean, responsive, and intuitive web application designed for students and hostelers to track daily expenses, visualize category-wise spending, and stay within their monthly budget limits.

---

## 🚀 Live Demo
🔗 **[View Live Project](https://YOUR-GITHUB-USERNAME.github.io/student-expense-tracker/)**

---

## ✨ Features
- **Dynamic Balance Calculation:** Automatically updates total spent and calculates remaining balance in real time.
- **Budget Threshold Alerts:** Triggers a visual warning banner when monthly expenditures exceed 80% of the set budget.
- **Data Visualization:** Integrates **Chart.js** to generate interactive doughnut charts displaying category-wise breakdown.
- **Data Persistence:** Utilizes browser **LocalStorage** so that all expense logs persist across page refreshes.
- **Responsive Layout:** Built using modern CSS Grid and Flexbox for seamless usability across mobile and desktop screens.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (CSS Grid & Flexbox)
- **Programming Logic:** Vanilla JavaScript (ES6+)
- **Library:** [Chart.js](https://www.chartjs.org/) (Data Visualization)
- **Storage:** Browser LocalStorage API
